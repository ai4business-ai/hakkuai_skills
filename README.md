# Hakkuai Skills

Public Claude skills marketplace by [Hakku AI](https://hakku.ai).

## Installation

1. Claude Desktop → Customize → Add custom source
2. Enter: `ai4business-ai/hakkuai_skills`
3. Enable desired skills

## Skills

- **b2b-cold-outreach** — Генератор холодных B2B-сообщений для email, LinkedIn и мессенджеров
